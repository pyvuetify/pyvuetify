LocaleProvider
==============


.. aknowledgement::
    This page is a Python adaptation of the `official Vuetify documentation <https://vuetifyjs.com/en/components/locale-providers/>`__.
    All examples have been converted to pyvuetify syntax.

The locale provider allows you to provide specific default prop values to components in a section of your application

.. api::

    :py:class:`pyvuetify.LocaleProvider`

Locale
------

The :py:class:`pyvuetify.LocaleProvider` expects a prop **locale** which looks the same as the **locale** object that you can pass to ``createVuetify`` when creating your application.
