PullToRefresh
=============


.. aknowledgement::
    This page is a Python adaptation of the `official Vuetify documentation <https://vuetifyjs.com/en/components/pull-to-refresh/>`__.
    All examples have been converted to pyvuetify syntax.

The PullToRefresh allows users to update content with a simple downward swipe on their screen. Works for Mobile and Desktop.

.. api::

    :py:class:`pyvuetify.PullToRefresh`
