MaskInput
=========


.. aknowledgement::
    This page is a Python adaptation of the `official Vuetify documentation <https://vuetifyjs.com/en/components/mask-inputs/>`__.
    All examples have been converted to pyvuetify syntax.

The :py:class:`pyvuetify.MaskInput` component allows you to enforce a format on user input according to specific patterns. This is particularly useful for fields like phone numbers, credit cards, dates, and other formatted data.

.. api::

    :py:class:`pyvuetify.MaskInput`
